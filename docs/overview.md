## 2. 프로젝트 소개

### 2.1 프로젝트 개요

DevLetter는 개발자 및 IT 종사자를 대상으로 사용자의 관심 분야에 맞는 IT 뉴스와 기술 정보를 제공하는 큐레이션 서비스이다.

다양한 IT 기술 블로그 및 뉴스 사이트에서 RSS 데이터를 수집하고, 수집한 뉴스를 기술 분야별로 분류하여 사용자에게 제공한다.

사용자는 자신의 관심 분야를 직접 선택할 수 있으며, 선택한 분야에 해당하는 뉴스를 웹 서비스에서 조회하거나 이메일 뉴스레터를 통해 정기적으로 받아볼 수 있다.

### 2.2 프로젝트 기획 배경

IT 기술과 관련된 뉴스 및 정보는 다양한 웹사이트와 플랫폼에 분산되어 있다.

사용자가 관심 있는 기술 분야의 최신 정보를 확인하기 위해서는 여러 사이트를 직접 방문해야 하며, 관심 분야와 관련 없는 정보까지 확인해야 하는 불편함이 존재한다.

또한 업무와 학습을 병행하는 개발자는 새로운 기술 동향을 지속적으로 확인하는 데 시간을 투자하기 어렵다.

이러한 불편함을 개선하기 위해 여러 출처의 IT 뉴스를 통합하고, 사용자의 관심 분야를 기반으로 필요한 정보를 제공하는 뉴스 큐레이션 서비스를 기획하였다.

### 2.3 해결하고자 하는 문제

1. 다양한 사이트에 분산된 IT 뉴스 및 기술 정보
2. 관심 분야의 정보를 찾기 위해 여러 웹사이트를 방문해야 하는 불편함
3. 사용자 관심 분야와 관련 없는 정보까지 확인해야 하는 비효율성
4. 업무 중 최신 기술 동향을 지속적으로 확인하기 어려운 문제

## 3. 서비스 주요 내용

### 3.1 주요 서비스

- 다양한 IT 뉴스 및 기술 블로그의 RSS 데이터 수집
- 수집된 뉴스의 저장 및 중복 데이터 관리
- 기술 분야별 뉴스 분류
- 사용자의 관심 분야 설정
- 관심 분야에 따른 개인화된 뉴스 조회
- 이메일을 통한 정기적인 뉴스레터 발송
- 사용자 간 기술 정보 공유 및 토론 기능 제공

### 3.2 주요 사용자

| 사용자 유형 | 설명 |
|---|---|
| 비회원 | 공개된 뉴스 목록 및 상세 정보 조회 |
| 일반 회원 | 관심 분야 설정, 뉴스레터 구독 및 커뮤니티 이용 |
| 관리자 | RSS 출처 및 뉴스 관리, 사용자 관리 |

### 3.3 서비스 핵심 가치

| 핵심 가치 | 설명 |
|---|---|
| 정보 통합 | 여러 사이트의 IT 뉴스를 한곳에서 확인 |
| 개인화 | 사용자가 선택한 관심 분야에 맞는 뉴스 제공 |
| 시간 절약 | 불필요한 정보 탐색 시간 최소화 |
| 정보 전달 | 이메일 뉴스레터를 통한 정기적인 정보 제공 |

## 4. 서비스 운영 및 처리 개요

### 4.1 뉴스 수집

- RSS를 제공하는 외부 뉴스 사이트 및 기술 블로그를 수집 대상으로 한다.
- 시스템이 RSS 데이터를 주기적으로 수집한다.
- 수집한 뉴스의 중복 여부를 확인하고 데이터베이스에 저장한다.

### 4.2 뉴스 분류

- 뉴스는 사전에 정의된 기술 분야별 카테고리로 분류한다.
- RSS 출처에 기본 카테고리를 지정할 수 있다.
- 관리자가 개별 뉴스의 카테고리를 수정할 수 있다.
- 초기 버전에서는 AI를 사용하지 않고 기본적인 분류 방식을 적용한다.

### 4.3 개인화된 뉴스 제공

- 사용자는 자신의 관심 분야를 직접 선택한다.
- 시스템은 사용자가 선택한 관심 분야와 뉴스 카테고리를 비교한다.
- 일치하는 분야의 뉴스를 웹 서비스에서 제공한다.

### 4.4 뉴스레터 발송

- 사용자는 이메일 뉴스레터 구독 여부를 설정할 수 있다.
- 시스템은 사용자의 관심 분야에 맞는 뉴스 목록을 생성한다.
- 정해진 주기에 따라 이메일 뉴스레터를 발송한다.

## 5. 향후 확장 방향

### 5.1 AI 기반 뉴스 큐레이션

- AI를 활용한 뉴스 자동 분류
- 뉴스 본문 또는 제공된 콘텐츠 기반 요약
- 사용자 관심 분야에 따른 개인화 추천

### 5.2 커뮤니티 기능 확장

- 뉴스별 댓글 및 토론 기능
- 사용자 간 기술 정보 공유
- 댓글 및 사용자 권한 관리

### 5.3 아키텍처 확장

- 모듈러 모놀리스 기반의 도메인 분리
- 도메인 간 의존성 최소화
- 서비스 분리 필요성 검토 및 MSA 전환 가능성 평가

## 6. 프로젝트 개발 방향

DevLetter는 실제 서비스 개발 과정을 경험하고 백엔드 개발 역량을 확장하기 위한 모의 프로젝트이다.

단순한 기능 구현보다는 요구사항 분석부터 설계, 구현, 테스트, 배포 및 운영까지 소프트웨어 개발 생명주기(SDLC)를 경험하는 것을 목표로 한다.

또한 기술 선택의 근거와 개발 과정에서 발생한 문제 및 해결 방법을 문서화하여 향후 기술 포트폴리오 및 면접 자료로 활용한다.
