## 2. 프로젝트 소개

### 2.1 프로젝트 개요

DevLetter는 개발자 및 IT 종사자를 대상으로 다양한 기술 블로그와 뉴스 사이트의 IT 뉴스를 한곳에서 제공하는 뉴스 큐레이션 서비스이다.

서비스는 RSS 기반으로 외부 뉴스 데이터를 수집하고, 수집한 뉴스를 기술 분야별 주제로 분류하여 제공한다. 비회원과 일반 회원은 동일한 최신순 뉴스 목록을 확인할 수 있으며, 원하는 주제를 직접 선택해 목록을 필터링할 수 있다.

주제 필터 선택 상태는 쿠키(Cookie) 또는 로컬 스토리지(Local Storage) 등 사용자 브라우저 환경에 저장하여 재방문 시에도 편리하게 이용할 수 있도록 한다. 구체적인 저장 방식과 만료·초기화 정책은 요구사항 분석 및 설계 단계에서 결정한다.

일반 회원에게는 이메일 뉴스레터 수신, 뉴스 스크랩, 커뮤니티 이용 기능을 추가로 제공한다.

### 2.2 프로젝트 기획 배경

IT 기술 관련 뉴스와 정보는 다양한 웹사이트 및 플랫폼에 분산되어 있다. 사용자가 최신 정보를 확인하기 위해 여러 사이트를 직접 방문해야 하며, 관심 주제와 무관한 정보까지 확인해야 하는 불편함이 있다.

DevLetter는 여러 출처의 IT 뉴스를 통합하고, 공통 뉴스 목록과 사용자가 직접 제어하는 주제 필터를 제공하여 정보 탐색의 편의성을 높이고자 한다. 또한 회원에게는 뉴스레터, 스크랩, 커뮤니티 기능을 제공하여 지속적으로 서비스를 이용할 동기를 제공한다.

### 2.3 해결하고자 하는 문제

1. 다양한 사이트에 분산된 IT 뉴스 및 기술 정보
2. 관심 있는 주제의 정보를 찾기 위해 여러 웹사이트를 방문해야 하는 불편함
3. 관심 주제와 무관한 정보가 섞여 있어 원하는 뉴스를 탐색하기 어려운 문제
4. 업무와 학습을 병행하면서 최신 기술 동향을 지속적으로 확인하기 어려운 문제
5. 유용한 뉴스를 별도로 보관하거나 다른 사용자와 의견을 나누기 어려운 문제

## 3. 서비스 주요 내용

### 3.1 주요 서비스

- 다양한 IT 뉴스 및 기술 블로그의 RSS 데이터 수집
- 수집된 뉴스 저장 및 중복 데이터 관리
- 기술 분야별 뉴스 분류
- 모든 사용자에게 동일한 최신순 뉴스 목록 제공
- 비회원 및 회원이 사용할 수 있는 주제별 뉴스 필터
- 브라우저 환경에 주제 필터 설정 저장 및 복원
- 회원 대상 이메일 뉴스레터 제공
- 회원별 뉴스 스크랩 및 보관
- 회원 전용 커뮤니티 제공

### 3.2 주요 사용자

| 사용자 유형 | 설명 |
|---|---|
| 비회원 | 공통 뉴스 목록 및 상세 조회, 주제 필터 사용 |
| 일반 회원 | 비회원 기능과 함께 뉴스레터 수신, 뉴스 스크랩, 커뮤니티 이용 |
| 관리자 | RSS 출처, 뉴스 분류 및 데이터, 사용자·커뮤니티 운영 관리 |

관리자 권한의 세부 범위와 일반 회원 기능의 허용 여부는 권한 정책 설계 단계에서 확정한다.

### 3.3 서비스 핵심 가치

| 핵심 가치 | 설명 |
|---|---|
| 정보 통합 | 여러 사이트의 IT 뉴스를 한곳에서 확인 |
| 개방적인 접근성 | 회원가입 여부와 관계없이 동일한 뉴스 목록 이용 |
| 사용자 주도 탐색 | 사용자가 원하는 주제를 직접 필터링 |
| 이용 편의성 | 브라우저에 필터 설정을 저장하여 재방문 시 복원 |
| 정보 전달 | 회원 대상 이메일 뉴스레터 제공 |
| 정보 보관 및 교류 | 스크랩과 커뮤니티를 통한 정보 축적 및 공유 |

## 4. 서비스 운영 및 처리 개요

### 4.1 뉴스 수집

- RSS를 제공하는 외부 뉴스 사이트 및 기술 블로그를 수집 대상으로 한다.
- 시스템이 RSS 데이터를 주기적으로 수집한다.
- 수집한 뉴스의 중복 여부를 확인하고 데이터베이스에 저장한다.
- RSS 출처별 수집 상태와 오류를 관리할 수 있도록 한다.

### 4.2 뉴스 분류

- 뉴스는 사전에 정의된 기술 분야별 주제로 분류한다.
- RSS 출처에 기본 주제를 지정하는 방식을 검토한다.
- 관리자가 개별 뉴스의 주제를 수정할 수 있도록 한다.
- 초기 버전에서는 AI를 사용하지 않고 규칙 또는 관리자 기반 분류를 적용한다.

### 4.3 뉴스 조회 및 필터링

- 비회원과 일반 회원에게 동일한 공개 뉴스 목록을 제공한다.
- 기본 정렬 기준은 최신순으로 한다.
- 사용자는 원하는 주제를 선택하여 뉴스 목록을 필터링할 수 있다.
- 선택한 필터는 브라우저 환경에 저장하고 재방문 시 복원한다.
- 필터 저장 방식, 복수 주제 선택 규칙, 초기화 방식 등은 요구사항 분석 단계에서 결정한다.
- 회원 여부나 뉴스레터 구독 여부에 따라 기본 뉴스 목록을 다르게 구성하지 않는다.

### 4.4 뉴스레터

- 일반 회원에게 이메일 뉴스레터 기능을 제공한다.
- 회원은 구독 여부를 설정하고 수신을 중단할 수 있다.
- 발송 주기, 발송 콘텐츠 구성, 주제 선택 기준 및 수신 동의 절차는 별도 요구사항으로 정의한다.

### 4.5 스크랩

- 일반 회원은 뉴스를 스크랩하고 자신의 스크랩 목록에서 다시 확인할 수 있다.
- 스크랩 데이터는 회원 계정과 연결하여 관리한다.

### 4.6 커뮤니티

- 일반 회원은 커뮤니티에서 게시글을 작성하고 다른 게시글을 조회할 수 있다.
- 댓글, 수정·삭제, 신고 및 관리자 관리 범위는 요구사항 분석 단계에서 정의한다.

## 5. 향후 확장 방향

### 5.1 AI 기반 뉴스 큐레이션

- AI를 활용한 뉴스 자동 분류
- 뉴스 본문 또는 제공된 콘텐츠 기반 요약
- 중복·유사 뉴스 탐지 및 관련 뉴스 연결

### 5.2 개인화 기능 확장

- 사용자 이용 이력 기반 추천
- 회원 계정과 브라우저 필터 설정 간 동기화 검토
- 관심 주제 기반 뉴스레터 구성 고도화

### 5.3 커뮤니티 기능 확장

- 뉴스별 댓글 및 토론
- 사용자 간 기술 정보 공유
- 좋아요, 북마크, 신고 및 운영 정책 고도화

### 5.4 아키텍처 확장

- 모듈러 모놀리스 기반 도메인 분리
- 도메인 간 의존성 최소화
- 서비스 분리 필요성 검토 및 MSA 전환 가능성 평가

## 6. 프로젝트 개발 방향

DevLetter는 실제 서비스 개발 과정을 경험하고 백엔드 개발 역량을 확장하기 위한 모의 프로젝트이다.

단순한 기능 구현보다는 요구사항 분석부터 설계, 구현, 테스트, 배포 및 운영까지 소프트웨어 개발 생명주기(SDLC)를 경험하는 것을 목표로 한다.

또한 기술 선택의 근거와 개발 과정에서 발생한 문제 및 해결 방법을 문서화하여 향후 기술 포트폴리오 및 면접 자료로 활용한다.
