# DevLetter 액터 정의서
(Actor Definition)

- 문서 단계: 시스템 분석 및 설계
- 문서 상태: 검토 완료
- 기준일: 2026-11-23

## 1. 액터 목록

| 액터 ID | 액터명 | 액터 유형 | 설명 |
|---|---|---|---|
| ACT-001 | 비회원 | 사용자 | 로그인하지 않고 공개된 뉴스 정보를 이용하는 사용자 |
| ACT-002 | 일반 회원 | 사용자 | 회원가입 후 로그인하여 뉴스 및 회원 기능을 이용하는 사용자 |
| ACT-003 | 콘텐츠 관리자 | 관리자 | 뉴스 콘텐츠와 사용자 토론 공간을 관리하는 관리자 |
| ACT-004 | 인프라 관리자 | 관리자 | RSS 수집 주기 및 시스템 운영 설정을 관리하는 관리자 |

## 2. 액터별 상세 정의

### 2.1 ACT-001. 비회원

- **액터 설명**: 시스템에 로그인하지 않고 이용하는 사용자
- **시스템 이용 목적**: 최신 뉴스 정보를 확인한다.
- **주요 권한**
  - 뉴스 목록 조회 및 상세 조회
  - 뉴스 목록 필터
  - 뉴스 댓글 조회
  - 회원가입
  - 로그인
- **제한 사항**
  - 비공개 뉴스 기사 접근 불가
  - 댓글 등록, 수정, 삭제 불가
  - 스크랩 등록 및 취소 불가
  - 관리자 기능 접근 불가

### 2.2 ACT-002. 일반 회원

- **액터 설명**: 시스템에 로그인한 사용자
- **시스템 이용 목적**: 최신 뉴스 정보를 확인하고 토론 및 스크랩 기능을 이용한다.
- **주요 권한**
  - 뉴스 목록 조회 및 필터
  - 뉴스 상세 조회
  - 뉴스 댓글 조회
  - 댓글 등록
  - 본인이 작성한 댓글 수정 및 삭제
  - 스크랩 등록 및 취소
  - 본인의 스크랩 목록 조회 및 관리
  - 뉴스레터 수신
  - 뉴스레터 수신 여부 변경
  - 비밀번호 변경
  - 로그아웃
  - 회원 탈퇴
- **제한 사항**
  - 비공개 뉴스 기사 접근 불가
  - 다른 회원의 스크랩 정보 접근 및 수정 불가
  - 다른 회원의 댓글 수정 및 삭제 불가
  - 관리자 기능 접근 불가

### 2.3 ACT-003. 콘텐츠 관리자

- **액터 설명**: 뉴스 콘텐츠와 사용자 토론 공간을 관리하는 역할
- **시스템 이용 목적**: RSS 뉴스 출처를 등록하고 뉴스 콘텐츠의 노출 여부 및 댓글의 공개 여부를 관리한다. 회원 현황을 확인한다.
- **주요 권한**
  - RSS 출처 등록, 조회, 수정, 활성화·비활성화 및 삭제
  - 뉴스 목록 조회 및 상세 조회
  - 뉴스 공개 여부 변경
  - 뉴스에 등록된 댓글 조회
  - 댓글 비공개 처리 및 비공개 댓글 목록 조회
  - 회원 현황 조회
- **제한 사항**
  - RSS 수집 주기 등 인프라 설정 기능 접근 불가
  - 댓글 등록 불가
  - 댓글 내용 수정 불가
  - 댓글 삭제 불가
  - 일반 회원의 스크랩 정보 접근 및 수정 불가

### 2.4 ACT-004. 인프라 관리자

- **액터 설명**: 시스템의 자동 처리 및 운영 환경을 관리하는 역할
- **시스템 이용 목적**: 시스템이 자동으로 수행하는 기능의 실행 조건과 운영 설정을 관리한다.
- **주요 권한**
  - RSS 수집 주기 설정
  - 시스템 운영 설정
- **제한 사항**
  - 뉴스 공개 여부 및 댓글 공개 여부 등 콘텐츠 설정 기능 접근 불가
  - 회원 현황 조회 불가

## 3. 사용자 계정 정책

1. 일반 회원은 공개 회원가입을 통해 직접 계정을 생성할 수 있다.
2. 회원의 로그인 ID는 이메일 주소를 사용하며, 중복된 이메일 주소로 가입할 수 없다.
3. 초기 버전에서는 이메일 주소 형식만 검증하고 이메일 소유 확인 절차는 생략한다.
4. 비밀번호는 정해진 정책에 따라 검증하고 안전한 해시 형태로 저장한다.
5. 일반 회원가입을 통해 관리자 권한을 부여받을 수 없다.
6. 로그인 실패 횟수에 따른 계정 보호 정책을 적용한다.
7. 회원은 본인 확인 후 계정을 탈퇴할 수 있다.
8. 회원 탈퇴 시 회원 정보와 스크랩 정보는 삭제하며, 작성한 댓글은 서비스 정책에 따라 유지한다.
9. 탈퇴한 회원의 동일 이메일 주소 재가입 허용 여부는 별도 정책으로 결정한다.

## 4. 관리자 계정 정책

1. 관리자 계정은 일반 회원의 공개 회원가입을 통해 생성할 수 없다.
2. 관리자 계정은 시스템 초기 구축 또는 승인된 관리자 계정 발급 절차를 통해 생성한다.
3. 관리자 계정은 콘텐츠 관리자와 인프라 관리자 역할을 구분하여 부여한다.
4. 관리자 계정은 담당 역할에 필요한 최소 권한만 부여받는다.
5. 관리자 계정은 일반 회원의 댓글 작성 및 개인화 기능을 기본적으로 사용할 수 없다.
6. 관리자 계정의 주요 관리 작업은 이력으로 기록한다.
7. 관리자 계정의 인증 및 접근 보안은 일반 회원보다 강화된 정책을 적용한다.
8. 관리자는 관리자 업무 계정과 별도로 일반 회원 계정을 보유할 수 있다. 일반 회원 기능을 이용할 때는 일반 회원 계정으로 로그인한다.

## 5. 권한 정책 및 미확정 사항

| 항목 | 현재 정책 |
|---|---|
| 콘텐츠 관리자와 인프라 관리자 권한 | 역할별로 분리하며 상호 담당 영역에 접근할 수 없다. |
| 관리자와 일반 회원 계정 | 업무 계정과 일반 서비스 이용 계정을 분리한다. 한 사람이 각각의 계정을 보유할 수 있다. |
| RSS 수집 현황 조회 | 요구사항에는 관리자 메뉴로 정의되어 있으나, 담당 관리자 역할은 추가 결정이 필요하다. |
| 관리자 일반 회원 기능 | 관리자 계정은 일반 회원 기능을 기본적으로 사용하지 않는다. |
