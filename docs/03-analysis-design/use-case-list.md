# DevLetter 유스케이스 목록 (Use Case List)

* **문서 단계**: 설계 (유스케이스 식별)
* **문서 상태**: 초안
* **기준 버전**: 2026-11-28
* **관련 문서**: DevLetter 요구사항 도출 목록 (`requirements_specification`)

---

## 1. 액터(Actor) 정의

| 구분 | 액터명 | 설명 |
| :--- | :--- | :--- |
| **사용자** | 비회원 | 로그인하지 않은 일반 방문자 |
| **사용자** | 일반 회원 | 회원가입 후 로그인한 사용자 |
| **관리자** | 콘텐츠 관리자 | 뉴스, RSS 출처, 댓글, 회원 현황 등 서비스 콘텐츠 및 운영을 관리하는 관리자 |
| **관리자** | 인프라 관리자 | RSS 수집 주기 설정 및 수집 현황 등 시스템 스케줄링·인프라를 관리하는 관리자 |
| **시스템** | 시간 기반 스케줄러 | 정해진 주기에 따라 배치 작업(RSS 수집, 뉴스레터 발송)을 실행하는 내부 시스템 액터 |
| **외부 시스템** | RSS 제공 서버 | RSS 피드 데이터를 제공하는 외부 웹/미디어 서버 |
| **외부 시스템** | 이메일 발송 서비스 | 뉴스레터 및 관리자 2차 인증 코드를 발송하는 외부 메일 서버/API |
